ATUE COMO:

Você é um UX/UI Designer Sênior, Desenvolvedor Front-end Sênior e Arquiteto de Software especializado na criação de websites institucionais modernos, responsivos e de alta qualidade visual.

Você deverá desenvolver um website institucional para a campanha do candidato Professor Witer Naves.

O projeto deve ser desenvolvido com aparência profissional, moderna e visualmente impactante, inspirado na identidade visual e estrutura das referências fornecidas pelo cliente, mas NÃO deve ser uma cópia literal do site de referência.

==================================================
1. CONTEXTO DO PROJETO
==================================================

O website será o portal oficial da campanha do Professor Witer Naves.

A identidade conceitual do projeto é:

"O TOCANTINS DE TODA NOSSA GENTE"

O plano de governo está organizado em três grandes princípios:

1. DIREITO DA GENTE
2. BEM-ESTAR DA GENTE
3. BEM-QUERER DA GENTE

Esses três princípios devem funcionar como o eixo visual e estrutural de todo o website.

O site deverá apresentar uma síntese visual e acessível do material recebido do cliente.

IMPORTANTE:

O website NÃO deve simplesmente reproduzir o PDF inteiro.

O PDF deve funcionar como o documento completo do plano de governo, enquanto o website deve apresentar uma versão resumida, visual e navegável das principais ideias.

Sempre que houver necessidade de informações que não estejam no material fornecido, utilizar placeholders claramente identificados.

NUNCA inventar:
- biografia do candidato;

==================================================

REGRA 3:

Não inventar notícias.

REGRA 4:

Não inventar redes sociais.

REGRA 5:

Não inventar números ou estatísticas.

REGRA 6:

Não inventar informações biográficas.

REGRA 7:

Quando uma informação não estiver disponível, utilizar placeholder.

REGRA 8:

O conteúdo oficial fornecido pelo cliente tem prioridade.

REGRA 9:

O site deve resumir o Plano de Governo, não reproduzi-lo integralmente.

REGRA 10:

A identidade visual deve ser inspirada na referência fornecida, mas o resultado deve ser uma criação própria.

==================================================
29. EXPERIÊNCIA FINAL
==================================================

O resultado deve parecer um website desenvolvido por uma agência profissional.

Ao acessar a Home, o visitante deve imediatamente entender:

1. Quem é o candidato;
2. Qual é o conceito da campanha;
3. Quais são os três princípios;
4. Onde encontrar as propostas;
5. Como acessar o Plano de Governo;
6. Como participar.

A navegação deve ser simples.

A experiência deve ser visual.

Os textos devem ser curtos.

Os elementos importantes devem ter destaque.

O site deve transmitir:

"MODERNO + HUMANO + INSTITUCIONAL + REGIONAL + PARTICIPATIVO"

==================================================
30. RESULTADO ESPERADO
==================================================

Entregar:

- todas as páginas estruturadas;
- navegação funcionando;
- menu responsivo;
- links internos funcionando;
- botões funcionando;
- animações;
- componentes reutilizáveis;
- responsividade;
- formulários com validação;
- SEO básico;
- acessibilidade;
- estrutura pronta para receber imagens e conteúdos oficiais;
- estrutura pronta para receber o PDF;
- código limpo e organizado.

Antes de finalizar, revisar todas as páginas procurando:

- textos duplicados;
- links quebrados;
- inconsistências visuais;
- problemas de responsividade;
- informações inventadas;
- elementos sem função;
- erros de português;
- problemas de contraste;
- botões sem destino.

O resultado final deve ser visualmente próximo da referência fornecida pelo cliente em termos de impacto, cores, organização e linguagem visual, porém com identidade própria e uma arquitetura de informação mais completa.
